# 本地资产归档规范

为了避免过程文件散落，当前统一约定：

- 所有本地化过程资产归档到 `D:\Project`

## 推荐目录

- `D:\Project\docs`
  - 过程稿
  - 中间版 PRD
  - 临时分析报告

- `D:\Project\data`
  - 原始数据
  - 实验拉数结果
  - 清洗前后数据文件

- `D:\Project\scripts`
  - 临时 SQL
  - 自动化脚本
  - 一次性处理程序

- `D:\Project\runtime`
  - 机器人接入配置
  - 本地运行日志
  - 调试产物

## 使用原则

- 最终协作文档优先回飞书云文档
- 最终归档优先回 Notion
- 本地目录主要存过程资产，不作为最终协作界面
