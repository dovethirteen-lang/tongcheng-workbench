# 飞书工作台前台说明

这不是最终嵌入飞书的发布版，但已经是按“飞书工作台前台”去做的第一版前端骨架。

## 定位

- 这是正式前台方案的本地实现
- 不再把本地 HTML 当成长期主前台
- 后续目标是迁移到飞书工作台 / Block 形态

## 当前页面包含

- 数据告警
- 待办池
- 文档状态
- 当前能力现状
- 版本规划
- 反馈池

## 使用方式

先生成前台数据：

```powershell
cd D:\CodeX\工作流设计\同程产品工作台
py .\scripts\render_feishu_frontend.py
```

然后打开：

- `D:\CodeX\工作流设计\同程产品工作台\09_feishu_frontend\index.html`

如果要本地起静态服务，可以直接在 `09_feishu_frontend` 目录下跑：

```powershell
py -m http.server 4390
```

再访问：

- `http://127.0.0.1:4390`
